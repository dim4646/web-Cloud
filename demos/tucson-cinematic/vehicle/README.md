# Vehicle photos

`photos/01.jpg` … `photos/15.jpg` are real photos of the actual **blue 2016
Hyundai Tucson** being sold, in walk-around order (engine bay → front → side →
rear → boot → interior). They are the single source of images for both the
hero background and the photo gallery — see `src/data/photos.ts`.

To add, remove, or reorder photos: drop the files here (keep the zero-padded
numeric naming) and update the `galleryPhotos` array and `heroPhoto` constant
in `src/data/photos.ts` to match.
